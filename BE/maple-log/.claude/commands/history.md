# /history 스킬

이 대화에서 작업한 내용을 `/Users/choijehyuk/Desktop/Workspace/MapleLog/history/` 폴더에 마크다운 파일로 정리합니다.

## 실행 방법

1. 오늘 날짜를 `YYYY-MM-DD` 형식으로 확인한다.
2. 파일명을 `YYYY-MM-DD_<작업-제목-kebab-case>.md` 형식으로 정한다.
   - 같은 날 여러 파일이 있으면 `_2`, `_3` 접미사를 붙인다.
3. 아래 템플릿을 채워 파일을 작성한다.
4. 완료 후 파일 경로를 사용자에게 알린다.

## 파일 템플릿

```markdown
# <작업 제목>

**날짜**: YYYY-MM-DD  
**작업 범위**: BE / FE / BE+FE

## 배경 및 목적

왜 이 작업을 했는지, 어떤 문제를 해결하는지 1~3줄로 요약.

## 변경 파일 목록

| 파일 경로 | 변경 유형 | 주요 내용 |
|-----------|-----------|-----------|
| `경로/파일.java` | 신규 / 수정 | 한 줄 요약 |

## 주요 변경 내용

### 백엔드 (BE)

변경한 로직, 새로 추가한 엔드포인트·DTO·서비스 메서드 등을 설명.

### 프론트엔드 (FE)

변경한 컴포넌트·페이지·API 호출·타입 등을 설명.

## 동작 흐름

새로운 기능이나 수정된 플로우를 단계별로 서술.

## 주의사항 / 연관 사항

- 다음 작업 시 참고할 사항
- 알려진 제약이나 추후 개선 포인트
```

## 클로드 참고 지침

- `/history`를 실행하면 **현재 대화**에서 다룬 작업을 위 양식으로 작성한다.
- 파일 작성 전 `history/` 폴더 내 기존 파일을 `ls`로 확인해 중복 날짜 여부를 체크한다.
- 작성 완료 후 `MEMORY.md`와 메모리 파일에 "최근 작업" 항목을 갱신한다.
- 이후 대화에서는 `history/` 폴더의 파일들을 먼저 훑어보고 맥락을 파악한다.
